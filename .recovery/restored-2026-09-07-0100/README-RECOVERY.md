# Восстановленный снимок сайта

Это резервная копия восстановленного состояния сайта на основе локальной истории VS Code за ночь 6–7 сентября 2026 года.

Изображения не дублируются: они не были затронуты откатом и остаются в корневой папке `uploads/`.

Чтобы повторно восстановить сайт, скопируйте HTML/JS-файлы из этой папки в корень проекта, а файлы из `design-tokens/` — в одноимённую папку проекта.
